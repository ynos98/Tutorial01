# Unit3

## ビルドツール紹介１ ～ tower ～
``||player: チャットコマンド||``を出して、名前を **tower** にしよう。<br>
チャットコマンドの中に ``||easyBlock: 次のブロックで ～ タワーをつくる||`` を入れよう。<br>
⇒ 材料・サイズを指定して、タワーを自動作成できる。

### ~ tutorialhint
```blocks
player.onChat("run", function () {
    easyBlock.agentBuildTower(STONE, 3, 3, 1)
})
```
```ghost
player.onChat("run", function () {
    easyBlock.agentBuildTower(STONE, 3, 3, 1)
})
```

## ビルドツール紹介２ ～ floor ～
``||player: チャットコマンド||``を出して、名前を **floor** にしよう。<br>
チャットコマンドの中に ``||easyBlock: 次のブロックで ～ ユカをつくる||`` を入れよう。<br>
⇒ 材料・サイズを指定して、床を自動作成できる。<br><br>

※ブロックの代わりに乱数を指定すると...？

### ~ tutorialhint
Minecraftのブロックは全て数が割り当てられているから、数字でも指定できるのだ。設置できないブロックの場合は、すぐにアイテム化するぞ。
```blocks
player.onChat("run", function () {
    easyBlock.agentBuildFloor(randint(1, 240), 3, 3)
})
```
```ghost
player.onChat("run", function () {
    easyBlock.agentBuildFloor(randint(1, 240), 3, 3)
})
```
